# TabNest 1.2 界面设计（Windows 11 原生软件风格）

## 布局
| 区域 | 规格 |
|---|---|
| 标题栏 | 32px 自绘（无边框窗口），拖拽区 + 最小化/最大化/关闭；Win11 启用 Mica |
| 菜单栏 | 文件/编辑/视图/快照/工具/帮助，Alt 显示访问键，Alt+字母 打开 |
| 工具栏 | 立即快照 · 快照并关闭 · 打开 · 移入收藏夹 · 检查链接 · AI 摘要 · 删除 · 搜索框 |
| 导航树 | 概览、浏览器（数量 / ⚠ 旧快照标记）、每日快照（年/月/日）、收藏夹（嵌套，计数含子级）、未整理（徽标）、重复项、回收站 |
| 分隔条 | 左右均可拖动，宽度存于 localStorage |
| 数据网格 | 虚拟滚动；列：图标/标题/网址/域名/来源浏览器/首次出现/最后出现/状态/收藏夹；可排序、可调列宽；Ctrl/Shift 多选；行高 28px（紧凑）/36px（舒适） |
| 属性窗格 | 选中项详情、链接状态、AI 摘要/关键词、可编辑备注 |
| 状态栏 | 24px：总数、已选、今日快照、扩展连接状态 |

## 视觉
- 字体：Segoe UI Variable / Microsoft YaHei UI 回退系统字体
- 强调色 #0067C0（深色 #4CC2FF），圆角 4px，1px 细边框
- 主题：跟随系统 / 浅色 / 深色（`html[data-theme]` 覆盖系统偏好）

## 对话框
Windows 风格标题 + 底部右对齐按钮。设置为选项卡式：常规/浏览器/扩展/AI/备份/关于。整理（Triage）为紧凑对话框。

## 快捷键
Delete 删除到回收站 · Enter 打开 · Ctrl+A 全选 · F2 编辑标题 · F5 立即快照 · Ctrl+F 搜索 · Ctrl+K 命令面板 · Ctrl+, 设置

## 安全
保持 contextIsolation + sandbox + CSP + Zod IPC 白名单 + 令牌配对本地 API；快捷键由渲染进程处理（无边框窗口下原生菜单加速键不可用）。
