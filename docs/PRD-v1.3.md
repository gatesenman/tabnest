# TabNest 页签巢 v1.3 PRD —— 「可信、零门槛、渐进整理」

> **1.3.5 决策**：浏览器扩展非必需，已整面移除。核心路径 = 会话文件 + 快照&关闭。

> 作者：产品 · 2026-10-14 · 基线版本 1.2.0（桌面软件风格 UI）

## 1. 背景与一句话目标
1.2 把界面做成了「像软件」，但用户在真实 Windows 电脑上的第一反应是 **「和打开的网页数量对不上」**。数字不可信 → 用户不敢关浏览器 → 产品核心价值（放心关、随时找回）失效。
**v1.3 目标：让每一个数字都能被解释，让几百个标签不再让人畏惧。**（1.3.5：不依赖浏览器扩展）

## 2. 用户画像
| 画像 | 描述 | 关键诉求 |
|---|---|---|
| **小明（核心）** | 知识工作者，每天开数百个标签，6 个浏览器并存（Chrome 7 个配置、Edge 366 标签、Brave、Vivaldi、Opera、Firefox），「怕关、从不整理」 | 关掉也不丢；数字可信；整理不费劲 |
| 收藏癖 | Chrome 562 个书签、Edge 68、Vivaldi 26，散落各处，重复、失效混杂 | 一处看全部书签，去重、清理后导回 |
| 偶尔误关者 | 昨天误关了窗口 | 一键找回「昨天还在、今天没了」的标签 |

## 3. 核心任务（JTBD）
1. **放心关**：一键快照并关闭（全部或单个浏览器），关之前确信数字是对的。
2. **找回**：按天/按浏览器/按「昨天消失」找回，并 **在原浏览器里一键还原**。
3. **渐进整理**：每天 5 分钟，系统给建议，我批量点「接受」。
4. **统一书签**：所有浏览器的书签放在一起、标注来源、去重、查死链、导出干净的 HTML。

## 5. 方案与决策
### 5.1 数量对账（P0）—— 「为什么不一样」必须说清楚
每个浏览器一张对账卡：
`存档读取（原始）` · `已过滤（新标签页/内部页）` · `去重后` · `今日快照中` + 存档时间。
自动生成「差异原因」中文解释，并给出 **一键修复**：
- 文件被锁定 → 「只快照并关闭此浏览器」（关闭后浏览器会写出最新会话）。
- 存档超过 30 分钟 → 标黄并提示同上。
- 有过滤/去重 → 写明具体数字。
**决策**：不「猜」实时数字；只展示我们确实读到的，并明确它的时间点。

### 5.2 锁定浏览器（原「扩展零门槛」，1.3.5 改方案）
- **不依赖浏览器扩展**：桌面端直接读会话文件；锁定浏览器用「只快照并关闭此浏览器」/ 快照并关闭流程（先关后读）。
- **决策**：扩展表面整面删除（含本地配对 API 127.0.0.1:17831）。

### 5.3 渐进整理（P0）
「整理建议」节点：
- **智能分组**（本地启发式）：同站点 ≥3 个 → 站点组；其余按标题/路径关键词聚类 → 主题组；给出建议收藏夹名，一键「接受」批量建夹并移入。云端 AI 可选（沿用已有设置）。
- **建议归档**：「N 个标签已超过 7 天未再出现」→ 一键移入「归档」。
- **书签里已存在**：未整理标签中已在已导入书签里的 → 一键移出待整理（移入对应书签夹）。
- **每日 5 分钟目标**：今日整理 X/20，连续天数 🔥 streak（基于整理时间戳）。

### 5.4 标签生命周期（P0）
`新出现`（首次出现于最近一次快照日）→ `持续打开`（≥2 天出现且仍在）→ `已关闭`（最近快照日不在）→ `已整理`（已进收藏夹）/ `已归档`（在「归档」夹）。
网格新增「状态」列与筛选；新节点 **「昨天消失」** = 昨天在、今天不在、未整理，用于误关找回。

### 5.5 还原（P1）
选中/整天/整组 →「在原浏览器还原」：按来源浏览器分批，用 exe + 新窗口打开；>50 个先确认。

### 5.6 书签一等公民（P1）
「导入所有浏览器书签」→「书签」根下每个来源一棵树（带来源名）；跨浏览器重复数提示；可批量查死链；「导出干净书签 HTML」（去重、排除失效）。

### 5.7 可靠性（P0/P1）
- 更新源为占位仓库时**不检查**，设置里显示「未配置更新源」。
- 首次运行检测残留数据（有数据但未完成引导、或旧版本），提供「清空并重新开始」。
- 自动快照默认开启（30 分钟 + 休眠/关机/锁屏），状态栏显示「自动快照 · 下次 HH:MM」。

### 5.0 先修复「快照为 0」（P0，最高优先）
- 所有时间戳转换统一走 `safeIso/safeMs`（`Number.isFinite` + 1995…now+2 天合理范围），无效值记为空，绝不抛错；单个浏览器读取失败只记录日志、继续其它浏览器。
- 启动 3 秒后自动快照；自动快照不再依赖引导完成（默认每 30 分钟 + 休眠/关机/锁屏）。
- 浏览器节点直接显示该浏览器**当前打开**的标签（来自读取结果），未保存时顶部提示「N 个尚未存入今日快照 · [立即存入]」，不会再出现「有数字却为空」。
- 自动更新：占位仓库时完全不检查，默认关闭，设置中显示「未配置更新源」。

### 5.9 AI 全自动整理（P0）
- **自动整理**（默认开启）：每次快照后自动给未整理标签分类；置信度 ≥ 阈值（默认 75%）直接移入收藏夹，不足的留在「未整理」并进入「待确认建议」。
- **引擎**：本地离线（默认）= 约 330 个中外常用网站知识库（含子域名/路径） + 标题关键词 + TF-IDF 聚类；可选云端 LLM（OpenAI 兼容：OpenAI / DeepSeek / 通义千问 / Kimi），批量 JSON 输出、结果缓存。**只有用户勾选「使用云端 AI」且填写 Key 后才会发送数据**。
- **自动调整分类体系**（每晚 02:00 后复查一次，也可手动「立即整理」）：相似项 > 8 个时新建收藏夹；近空且相似的收藏夹合并；含糊名称（新建文件夹/杂项…）按内容重命名；过大的收藏夹按站点细分子收藏夹。
- **规则学习**：用户手动移动 = 纠正，自动学到「网站 → 收藏夹」和多站共享关键词规则，之后优先应用（规则置信度最高）。
- **自动整理记录**：每一次自动变更一条记录，可单条撤销，也可「撤销今天全部」。
- **后台补全描述与关键词**：每 2 分钟 10 个（本地；开启云端后用云端）。
- 界面：导航树「智能整理」= 引擎状态 + 记录/撤销 + 待确认建议 + 学到的规则。

### 5.8 概览（P1）
今日标签数、今日新增、今日关闭、待整理、本周已整理、连续整理天数、各浏览器状态（存档 HH:MM / 锁定）、7 天折线。

## 6. 指标
| 指标 | 定义 | 目标 |
|---|---|---|
| 数字信任度 | 对账卡中「已解释」差异占比 | 100% 差异有原因 |
| 锁定浏览器可恢复 | 对锁定浏览器执行「只快照并关闭此浏览器」后能写入今日快照 | 手动验收 |

| 整理连续天数 | streak | 中位数 ≥ 3 |

| 日志噪声 | 更新 404 错误数 | 0 |

## 7. 范围外（v1.3 不做）
- 云同步 / 账号体系；移动端。
- 直接写入浏览器书签数据库（只导出 HTML 让用户自己导入，避免损坏书签）。
- （已取消）应用商店上架扩展——1.3.5 起产品不依赖扩展。
- 不经用户批准的任何自动关闭浏览器。

**延期**：

- 导入书签本身不自动重新分类（保留用户在浏览器里的原有结构；只有新标签和未整理项会被自动归类）。
- 云端 AI 参与「分类体系复查」（目前复查用本地引擎，云端只用于逐条分类与描述）。
- 书签直接回写浏览器数据库；单配置级别的「只关闭此配置」。
- 链接死链检查仍为手动触发（不在后台自动跑，避免大量网络请求）。

## AI 深度增强（v1.4.0）

目标：不加导航入口，把已有 AI 做深、做准、做快。

| 项 | 方案 | 验收 |
|---|---|---|
| 内容感知元信息 | utilityProcess 抓取网页（限速/超时/512KB/可关闭）→ 提取 title/meta/og/h1-h3/首段 → 中英文分词关键词；云端只收纯文本片段 | 详情窗格显示「网页正文：已读取」；关键词含正文概念 |

## AI 摘要卡片（v1.4.1）
