## [1.1.1] - 2026-10-14

### 修复（Windows：浏览器运行时读取实时会话）
- Edge / Vivaldi 运行时会**独占锁定**当前 `Sessions/Session_*`（Node / PowerShell / `copy` / 无管理员 `esentutl /vss` 都读不了），之前因此显示 0 个标签。现在：

### 安全
- `contextIsolation` 开启、`nodeIntegration` 关闭、渲染进程 `sandbox` 开启

- 禁止渲染进程跳转页面和打开新窗口；拒绝所有权限请求；只允许打开 http(s) 链接
- 本地 API 只监听 127.0.0.1，写入需要每台安装各自生成的配对码（比较时防时序攻击），请求体上限 5 MB
